Start docker compose
docker compose up -d

Start docker compose and rebuild image
docker compose up -d --build

For starting dev env:
docker compose -f docker-compose.yaml -f docker-compose.dev.yaml up -d

For starting prod env:
docker compose -f docker-compose.yaml -f docker-compose.prod.yaml up -d

Re-build image with docker compose:
docker compose -f docker-compose.yaml -f docker-compose.dev.yaml up -d --build

Open container shell in terminal:
docker exec -it container_name sh

Open mongodb shell in terminal
docker exec -it e-commerce-app-mongo-1 sh

Connect with mongodb
mongosh -u root -p
